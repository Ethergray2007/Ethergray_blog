### ⚠️ 授权状态：未确认

这是**第三方画师的同人作品**，通过 Wallpaper Engine 创意工坊分发。
授权状况不明 —— 创意工坊的素材不等于可以自由用于公开网站。

**现在的处理**：

- 博客尚未公开上线，自用没有问题
- 原始 mp4 **没有**复制进仓库，只保留了压缩后的成品图

**真要公开挂站之前，建议二选一**：

```text
1. 换成自有素材（自己画的、自己渲染的、CC0 授权的）
2. 联系作者取得授权，并在页面上注明出处
```

**换图的方法**：把自己的图放到 `src/assets/images/hero-bg.png`，
然后跑 `node scripts/make-hero-bg.ts` 重新生成成品。
（该路径在 `.gitignore` 里，原图不会进仓库。）

## 筛选过程中排掉的素材

顺便记一下**为什么没用**其他几张，免得以后重复翻一遍：

```text
Mature / Questionable 分级的              直接排除（确有露骨内容）
scene 类型（初音未来、Blue Archive 等）     真素材打包在 scene.pkg 里，取不出来
                                          只有 preview.gif 这种方形缩略图
Web 类型（Nikke、Blue Archive 网页版）      本体是 1:1 手机壁纸，
                                          裁成 1920×600 只剩一块花瓣纹理
921617616/img/53478421_p0.png              Everyone 且是 16:9，但内容是
                                          水下动漫少女：撕破的裙子 + 溺水意象
kuroha（未标题-1_1.mp4）                   黑白素描线稿，带作者签名水印，
                                          情绪忧郁，而且画面过亮不适合压字
```

**结论**：那个文件夹是手机壁纸为主的库，
适合做**宽屏网页背景**的素材其实很少。

### 为什么选第 0 帧

一开始抽的是第 3 秒，结果人物闭着眼、嘴微张，表情有点怪。

后来从开头抽了 6 帧对比（0 / 0.5 / 1 / 1.5 / 2 / 2.5 秒），
又检查了整段视频的亮度分布：

```text
帧      平均亮度   暗部占比
t0       116.3     28.6%
t2.5     117.3     28.0%
t8       116.9     28.3%
t14      116.9     28.2%
```

**各帧亮度几乎完全一致** —— 说明视频从第一帧就是完整画面，
开头没有淡入。所以第 0 帧是干净可用的，而且人物眼睛睁开、
表情比第 3 秒自然得多。

（这个检查是必要的：如果视频开头有淡入，第 0 帧会是黑的或半透明的。）
