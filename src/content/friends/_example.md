复制这个文件、改掉字段、把 `order` 改成你想要的排序位置。

字段说明：

| 字段          | 必填 | 说明                            |
| ------------- | ---- | ------------------------------- |
| `title`       | 是   | 站点名称                        |
| `description` | 是   | 一句话简介                      |
| `url`         | 是   | 站点地址（必须带 `https://`）   |
| `avatar`      | 是   | 头像图片地址（外链即可）        |
| `order`       | 否   | 排序，小的在前，默认 999        |
| `online`      | 否   | 是否显示「在线」标记，默认 true |
