# 开始搭建 EtherGray Blog

最近开始搭建自己的个人博客，于是选择了 Astro 作为基础框架。

之前接触过一些前端技术，但一直没有认真做过一个完整的网站。相比从零开始写一个博客，使用成熟的模板可以把更多精力放在内容和后续功能上。

## 为什么选择 Astro

Astro 的一个特点是非常适合内容型网站。

博客的大部分内容其实都是：

- Markdown 文章
- 图片
- 页面
- 少量交互

并不需要每一个页面都运行大量 JavaScript。

Astro 可以把页面尽可能多地作为静态 HTML 输出，这对于博客这种网站非常合适。

## 为什么使用 AstroPaper

这次使用的是 AstroPaper。

它已经把博客最基础的功能准备好了，例如：

- 文章列表
- 标签
- 归档
- 搜索
- 深色 / 浅色模式
- RSS
- Markdown / MDX
- 自动生成页面

这样不用重新实现一个博客系统，可以直接在现有结构上修改。

## 接下来准备做什么

目前主要还是把模板改造成自己的博客。

准备先完成：

1. 中文界面
2. 修改网站信息
3. 清理模板自带的示例文章
4. 修改首页
5. 添加自己的文章
6. 部署到 Netlify

博客并不准备一次性把所有东西都设计好。

先把基础版本跑起来，然后在实际使用过程中不断修改。

毕竟真正使用之后，才知道哪些功能是需要的。

这也是建立这个博客的一个目的：

**把学习过程本身记录下来。**
